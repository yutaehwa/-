WebSnap PDF가 뭐예요?

📚 비유로 이해해요!
인터넷에서 재미있는 기사를 발견했는데, 인터넷이 없을 때도 보고 싶다면 어떻게 할까요?
WebSnap PDF는 마치 인터넷 프린터처럼, 웹페이지를 그대로 종이(PDF)에 찍어 보관해 줘요!
광고나 쓸데없는 버튼은 쏙 빼고, 내용만 깔끔하게 담아줘요. 😊
사용자 어디에 쓰나요?
📰 직장인뉴스·기사를 오프라인 보고용으로 저장
🎓 학생·연구자참고 자료·논문을 PDF로 보관
💻 개발자기술 문서를 로컬에 저장
🍳 일반 사용자레시피·여행 정보 등 즐겨찾기 대신 PDF 보관
🎯
목표: URL 입력 후 10초 이내에 PDF 생성! 한글과 영어 폰트가 모두 예쁘게 나와요.
📁

파일 구조 살펴보기

🏠 비유로 이해해요!
파일 구조는 마치 집 구조와 같아요.
app/ 폴더는 거실(사용자가 보는 화면), lib/ 폴더는 주방(요리하는 곳 = 핵심 로직), prisma/는 냉장고(데이터 보관)예요!
websnap-pdf/
├── app/ ← 화면과 API가 모여 있는 곳
│ ├── api/
│ │ ├── convert/route.ts ← URL 1개 → PDF 변환
│ │ ├── batch/route.ts ← URL 여러 개 → ZIP 변환
│ │ ├── v1/convert/route.ts ← 외부 개발자용 REST API
│ │ ├── preview/route.ts ← 변환 전 미리보기 사진
│ │ ├── history/route.ts ← 변환 기록 불러오기
│ │ ├── stripe/route.ts ← 결제 처리
│ │ └── auth/route.ts ← 로그인 처리
│ ├── batch/page.tsx ← 일괄 변환 화면
│ ├── dashboard/ ← 대시보드 화면
│ └── page.tsx ← 메인(홈) 화면
├── lib/ ← 핵심 기능 모음 (엔진실)
│ ├── pdf-converter.ts ⭐ PDF 만드는 핵심 코드
│ ├── storage.ts ← 파일 저장 (Supabase)
│ ├── prisma.ts ← 데이터베이스 연결
│ ├── rate-limit.ts ← 과도한 사용 제한
│ ├── api-key.ts ← API 키 암호화
│ └── url-validator.ts ← 위험한 주소 차단
├── prisma/
│ └── schema.prisma ← 데이터베이스 설계도
├── auth.ts ← Google 로그인 설정
└── package.json ← 사용하는 도구 목록
💡
가장 중요한 파일: lib/pdf-converter.ts — 이 파일이 실제로 PDF를 만드는 "심장" 역할을 해요!

기본 사용법 단일 변환

🍕 피자 주문처럼 쉬워요!
피자를 주문할 때 "어떤 피자, 몇 판"을 고르듯이,
WebSnap PDF도 "어떤 URL, 어떤 옵션"을 고르면 끝이에요!
  1. 1
    🌐 서비스 주소로 접속

    브라우저(크롬, 사파리 등)를 열고 WebSnap PDF 주소로 들어가요.

  2. 2
    📋 URL 붙여넣기

    저장하고 싶은 웹페이지 주소를 복사해서 입력창에 붙여넣어요.

    https://example.com/interesting-article
  3. 3
    ⚙️ 옵션 선택 (선택 사항)

    PDF 모양을 바꾸고 싶다면 아래 옵션을 골라요.

    옵션선택지설명
    📄 용지 크기A4 / LetterA4는 한국·유럽, Letter는 미국 기준
    📐 방향세로 / 가로세로(portrait)가 일반적
    ⬜ 여백없음 / 작게 / 보통 / 크게테두리 빈 공간의 크기
  4. 4
    🚀 [변환하기] 버튼 클릭!

    버튼을 누르면 서버가 웹페이지를 가져와서 PDF를 만들기 시작해요.

    🔄 변환 중이에요... (최대 30초)
    📡 페이지 열기 ✂️ 광고 제거 📄 PDF 생성 ✅ 완료!
  5. 5
    👀 미리보기 확인

    변환하기 전에 웹페이지가 어떻게 생겼는지 사진으로 미리 볼 수 있어요.

  6. 6
    ⬇️ PDF 다운로드!

    [PDF 다운로드] 버튼을 누르면 내 컴퓨터에 PDF가 저장돼요.

    🎉

    PDF 저장 완료!

여러 개 한꺼번에 일괄 변환

🛒 장보기처럼 생각해요!
마트에서 물건을 하나씩 따로 계산하는 것보다 한 번에 담아서 계산하는 게 편하죠?
일괄 변환은 URL을 여러 개 넣으면 한꺼번에 PDF로 만들어서 ZIP 파일 하나로 묶어줘요!
  1. 1
    🔑 Google 로그인 (필수!)

    일괄 변환은 로그인한 사용자만 쓸 수 있어요. Google 계정으로 로그인하세요.

  2. 2
    📍 /batch 페이지로 이동

    메인 화면에서 "일괄 변환" 메뉴를 클릭하거나 주소창에 /batch를 입력해요.

  3. 3
    📝 URL 목록 입력

    변환할 주소들을 줄바꿈(Enter) 또는 쉼표(,)로 구분해서 입력해요.

    # 이렇게 한 줄씩 입력해요:
    https://example.com/article1
    https://news.site.com/story
    https://blog.example.org/post-123
  4. 4
    🔢 개수 확인 (한도 주의!)

    입력창 위에 현재개수 / 최대개수가 표시돼요.

    플랜최대 URL 수
    🆓 무료(Free)5개
    ⭐ 프로(Pro)30개
  5. 5
    🚀 [ZIP으로 일괄 변환] 클릭

    최대 60초가 걸릴 수 있어요. 3개씩 동시에 변환해요.

  6. 6
    ⬇️ ZIP 파일 다운로드

    완료되면 websnap-batch-{날짜}.zip 파일이 생성돼요.
    압축을 풀면 각 URL별 PDF 파일이 들어있어요!

    📂
    ZIP 안에는 페이지제목.pdf 파일들이 있어요.
    같은 제목이 있으면 자동으로 제목-1.pdf, 제목-2.pdf처럼 번호를 붙여줘요.

개발자 REST API 고급 기능

🤖 로봇 비서에게 시키는 것처럼요!
일반 사용자는 화면을 클릭하지만, 개발자는 코드로 직접 명령을 내릴 수 있어요.
API는 마치 비밀 문(API Key)을 열고 들어가 명령을 내리는 것과 같아요!
  1. 1
    🔑 API Key 발급

    대시보드 → API Key 섹션에서 키를 발급받아요. 절대 남에게 알려주면 안 돼요!

  2. 2
    📤 변환 요청 보내기

    아래 명령어를 터미널에서 실행하면 PDF가 바로 저장돼요.

    curl -X POST https://your-domain.com/api/v1/convert \
    -H "Authorization: Bearer 여기에_API_KEY_입력" \
    -H "Content-Type: application/json" \
    -d '{
    "url": "https://example.com/article",
    "options": {
    "format": "A4",
    "orientation": "portrait",
    "margin": "normal"
    }
    }' \
    --output article.pdf
  3. 3
    📩 응답 받기

    성공하면 PDF 파일을 바이너리(0과 1 데이터)로 받아요.

    상황응답
    ✅ 성공PDF 파일 바이너리 데이터 (Content-Type: application/pdf)
    ❌ 인증 실패{ "error": "유효하지 않은 API 키입니다." }
    ⚠️ 한도 초과{ "error": "일일 변환 한도를 초과했습니다." }
    🚫 잘못된 URL{ "error": "url 필드가 필요합니다." }
⚠️
일일 한도: 무료 플랜은 하루 5회, Pro는 100회까지 API를 쓸 수 있어요.

위험한 주소는 자동 차단!

🏥 백신처럼 나쁜 것을 막아요!
나쁜 사람이 WebSnap PDF를 이용해서 서버 내부 정보를 훔치려 할 수 있어요.
이를 SSRF 공격이라 부르는데, WebSnap PDF는 이런 주소들을 자동으로 막아요!

아래 주소들은 입력해도 변환이 거부돼요:

🚫 file://
🚫 localhost
🚫 127.0.0.1
🚫 192.168.x.x
🛡️
왜 막나요?
• file:// — 내 컴퓨터 파일을 몰래 열 수 있어요
• localhost / 127.x.x.x — 서버 자기 자신을 공격할 수 있어요
• 192.168.x.x — 회사 내부 네트워크에 침입할 수 있어요
⚡
추가 보안: IP당 분당 5회 변환 제한이 있어요. 너무 빠르게 많이 요청하면 잠시 차단돼요.

개발 환경 설정 개발자용

🧪 과학 실험실 준비하기!
직접 이 서비스를 내 컴퓨터에서 실행하고 싶다면, 먼저 "재료"를 준비해야 해요.
아래 순서대로 따라 하면 내 컴퓨터에서도 WebSnap PDF를 돌릴 수 있어요!
  1. 1
    📦 필요한 도구 설치 (의존성)

    프로젝트 폴더로 들어가서 아래 명령어를 실행해요.

    cd websnap-pdf
    npm install
  2. 2
    🔐 환경 변수 설정 (.env.local 파일 만들기)

    프로젝트 폴더에 .env.local 파일을 만들고 아래 내용을 채워요.

    # 데이터베이스 (Supabase PostgreSQL)
    DATABASE_URL=postgresql://user:password@host/dbname

    # 로그인 보안 키 (아무 랜덤 문자열)
    NEXTAUTH_SECRET=랜덤한_긴_문자열_여기에

    # Google 로그인 (Google Cloud Console에서 발급)
    GOOGLE_CLIENT_ID=xxx.apps.googleusercontent.com
    GOOGLE_CLIENT_SECRET=GOCSPX-xxx

    # Supabase 파일 저장소
    NEXT_PUBLIC_SUPABASE_URL=https://xxx.supabase.co
    SUPABASE_SERVICE_ROLE_KEY=eyJxxx...

    # 결제 (Stripe)
    STRIPE_SECRET_KEY=sk_test_xxx
    STRIPE_WEBHOOK_SECRET=whsec_xxx
    ⚠️
    .env.local 파일은 절대 GitHub에 올리면 안 돼요! 비밀번호가 들어있거든요.
  3. 3
    🗃️ 데이터베이스 준비 (마이그레이션)

    데이터베이스에 필요한 테이블들을 자동으로 만들어요.

    npx prisma migrate dev
  4. 4
    🚀 개발 서버 실행!

    아래 명령어를 실행하면 내 컴퓨터에서 서비스가 시작돼요.

    npm run dev

    실행 후 브라우저에서 http://localhost:3000으로 접속하면 돼요! 🎉
